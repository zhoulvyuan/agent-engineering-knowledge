## 需要重点区分的三组概念

这是本知识库中**最容易混淆、也最值得专门辨析**的三组词。

### 1. Context vs Memory vs State

这三个词经常被混用，本库的划分标准：

| 概念 | 时间尺度 | 归属域 | 一句话 |
| --- | --- | --- | --- |
| **Context** | 单次推理 | [01-基础认知](../01-基础认知/03-Context与上下文窗口.md) | 模型这一次能看到的 |
| **Memory** | 跨会话 | [03-Agent核心](../03-Agent核心/05-Memory.md) | 系统长期记住的 |
| **State** | 单次任务运行期 | [08-Agent工程化](../08-Agent工程化/01-State-Management.md) | 这个任务当前进行到哪了 |

关系：**State 和 Memory 都是通过被注入 Context 才能影响模型行为。**

### 2. Tool vs Skill vs Plugin vs MCP

| 概念 | 本库的定位 |
| --- | --- |
| **Tool** | 一个可调用的能力单元（类比：函数） |
| **MCP** | 工具接入的**协议标准**（类比：USB 接口） |
| **Skill** | 按需加载的**能力封装**，可含指令+工具+知识（类比：操作手册） |
| **Plugin** | 平台侧的**扩展机制**（类比：应用商店插件） |

详见 [05-工具与扩展](../05-工具与扩展/README.md)。

### 3. Workflow vs Agent

| 概念 | 决策权归属 |
| --- | --- |
| **Workflow** | 流程由代码写死，确定性 |
| **Agent** | 流程由模型动态决定，非确定性 |
| **Agentic Workflow** | 骨架固定，关键节点交给模型 |

详见 [Workflow vs Agent](../07-Workflow编排/03-Workflow-vs-Agent.md)。
