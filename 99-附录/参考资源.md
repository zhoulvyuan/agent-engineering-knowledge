# 参考资源

> **原则**：只收录**真正读过并用得上**的资源。不要做成链接收藏夹。

## 分类方式

| 类别 | 说明 |
| --- | --- |
| 官方文档 | 一手信息，优先级最高 |
| 工程实践 | 别人的踩坑经验 |
| 原理补充 | 需要时查阅 |
| 工具 | 实际在用的 |
| 论文 | 只在需要追根溯源时读 |

## 记录规范

新增资源时，请同时写下：

1. **它解决我的什么问题** —— 不是"它讲了什么"
2. **我读到了什么程度** —— 通读 / 精读某一章 / 只看了结论
3. **我的判断** —— 值得反复看 / 看一次够了 / 不推荐
