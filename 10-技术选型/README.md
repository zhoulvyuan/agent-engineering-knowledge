# 10 技术选型

> 主线域 ｜ 目标：不追逐「最新技术」，而是能够根据实际问题进行判断。

## 本域定位

本域提供的是**判断框架**，而不是技术清单。但只有框架没有对象是不够的——
你迟早要在具体选项之间做决定。

**原地图的缺口**：第 11 章只有方法论，没有**选型对象**。以下四个选型对象
已登记为待建文件。

**给你的 Java 背景的提示**：`05-Java生态` 是本知识库中**最应该优先建的文件**。
你不是从零进入 AI 领域的人——Spring AI / LangChain4j 让你可以复用已有的
工程能力（依赖注入、事务、可观测、企业集成），这是你相对于 Python 原生
开发者最实际的切入点。
