1. **LLM** — 先建立"它在做什么"的整体感觉
2. **Token** — 理解上下文和成本的计量单位
3. **Context** — 理解单次推理的信息边界（后面 Context Engineering 的基础）
4. **Embedding** — 为后面的 RAG 和语义检索做准备
