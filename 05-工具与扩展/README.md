# 05 工具与扩展

> 主线域 ｜ 目标：理解 Agent 如何获得「行动能力」和外部能力。

## 本域定位

本域回答：**Agent 的手和脚从哪来。**

三个概念容易混淆，本知识库的划分标准是：

| 概念 | 定位 | 类比 |
| --- | --- | --- |
| **Tool** | 单个可调用的能力单元 | 一个函数 |
| **MCP** | 工具接入的**协议标准** | USB 接口 |
| **Skill** | 按需加载的**能力封装**（含指令+工具+知识） | 一本操作手册 |
| **Plugin** | 平台侧的**扩展机制** | 应用商店里的插件 |

**优先级提示**：MCP 和 Skill 目前都是 🟡，但真正决定 Agent 可用性的是
**Tool 的设计质量**（schema、错误反馈、粒度、数量控制）。
原地图把 Tool 写得较浅，实际它是本域最需要深入的节点。
