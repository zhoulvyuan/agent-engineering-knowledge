# 07 Workflow 编排

> 主线域 ｜ 目标：理解确定性流程与 Agent 自主决策之间的边界。

## 本域定位

本域的核心只有一个问题，但它是**架构决策中最常被搞错的一个**：

> 这个环节，我应该**写死流程**，还是**交给模型自主决策**？

**本域最大的缺口是 `Workflow vs Agent`（🔴）**。没有明确判断标准时，
典型失败模式是两种：

- **过度 Workflow**：用一堆 if-else 硬编流程，模型只做文本填充，白白放弃了自主性
- **过度 Agent**：什么都交给模型决策，结果不可预测、不可测试、成本失控

**推荐判断标准**（待你验证后沉淀）：

| 信号 | 倾向 |
| --- | --- |
| 步骤固定、顺序确定 | Workflow |
| 需要根据中间结果决定下一步 | Agent |
| 错误代价高、需要可审计 | Workflow（+ HITL） |
| 输入形态高度不确定 | Agent |
| 需要与人协作、随时打断 | Agentic Workflow |
