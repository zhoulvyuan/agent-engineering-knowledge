# 11 架构设计

> 主线域 ｜ 目标：把前面的知识组合起来，形成完整系统设计能力。

## 本域定位

本域是**整个知识库的收口**，也是最终目标所在：

> 如果让我从零设计一个企业级 AI Agent 系统，我应该如何拆分？

**重要提醒**：本域全部是 ⚪，但它**不应该等到最后才看**。
架构不是"学完所有零件后再拼装"，而是**先有整体图景，再逐个填深**。

建议的做法：学完 [03-Agent核心](../03-Agent核心/README.md) 和
[04-Agent设计模式](../04-Agent设计模式/README.md) 后，就来本域画一张
**自己理解的架构图**，然后随着后续学习不断修正它。这张图的演化过程，
比最终画成什么样更有价值。

**结构决策**：原地图中 `2.5 AI Application Architecture` 与本域 `9.1` 重复，
已统一到本域。

1. **AI 应用架构** — 先建立最小完整图景
2. **Agent 架构** — 核心组件的划分
3. **Tool / 知识 / 记忆架构** — 三个支撑层
4. **多 Agent 架构** — 复杂度升级
5. **企业级 AI 架构** — 最终目标
