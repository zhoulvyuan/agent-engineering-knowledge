# 06 知识检索 RAG

> 主线域 ｜ 目标：理解 Agent / AI Application 如何获得外部知识。

## 本域定位

本域回答：**模型不知道的东西，怎么让它知道。**

**重要视角**：从 Agent 的角度看，**RAG 本质上是 Tool 的一种**
（一个"查资料"的工具）。它之所以独立成域，是因为它的工程复杂度远超普通工具
（切分、索引、检索、重排、更新）。

如果你在设计中纠结"这块该用 RAG 还是该做成 Tool"，可以简化判断：

> 需要**在生成前注入知识** → RAG；需要**在循环中主动查询** → Tool。

**结构决策**：`Embedding` 的唯一归属已移至 [01-基础认知](../01-基础认知/04-Embedding.md)，
本域只引用不重复定义。
